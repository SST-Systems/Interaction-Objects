Готовая система взаимодействия с объектами от первого лица для Unity.

Наведитесь на физический объект, чтобы подсветить его, затем возьмите его, держите на «руке» с учётом массы, отпустите или бросьте — а если объект уходит за стену, он отпускается автоматически. В комплекте — собственная обводка (Built-in RP и URP) и демо-контроллер.

## Как это работает

Всю работу выполняет один класс — `InteractionObjectTaker`. Его вешают на объект-«глаза» (обычно камеру или вращающийся с видом пивот). С фиксированным интервалом он пускает луч вдоль своей оси вперёд и сообщает о первом `InteractionObject` на пути, подсвечивая его обводкой, пока он под прицелом.

При взятии объект крепится к скрытому кинематическому `ConfigurableJoint` — «руке», — пружины которого настраиваются под массу объекта, поэтому и лёгкие, и тяжёлые предметы плавно следуют за камерой. Повторное взаимодействие отпускает объект; бросок толкает его вперёд силой, уменьшенной с учётом массы.

## Использование

### Настройка обработчика

Повесьте `InteractionObjectTaker` на трансформ, который направляет луч, — обычно основную камеру или пивот, вращающийся вместе с видом. Рука-джойнт, цикл рейкастов и подсветка обрабатываются внутри.

### Пометка объектов

Повесьте `InteractionObject` на каждый предмет, который игрок может взять. Компонент требует `Rigidbody` и `Outline` (оба добавляются автоматически), поэтому объект управляется физикой и может подсвечиваться.

> **Совет:** включите **Interpolate** на `Rigidbody` каждого предмета (Inspector → Rigidbody → *Interpolate → Interpolate*). Без этого визуал предмета дёргается между физическими шагами, пока вы его несёте.

### Управление из ввода

Вызывайте два публичных метода из своего слоя ввода (Input System, кнопки, собственный контроллер — что угодно):

```csharp
using SST.InteractionObjects;

public class PlayerInteractionInput : MonoBehaviour
{
    [SerializeField] private InteractionObjectTaker _taker;

    private void Update()
    {
        // Взять то, на что смотрите, или положить то, что держите.
        if (Input.GetKeyDown(KeyCode.E))
            _taker.Interaction();

        // Бросить объект.
        if (Input.GetMouseButtonDown(0))
            _taker.ThrowObject();
    }
}
```

## Настройки

**`InteractionObjectTaker`**

| Поле | Описание |
|---|---|
| `interactionDistance` | Максимальная дистанция, на которой можно взять объект. |
| `offsetStartRaycast` | Смещение начала луча вперёд от центра объекта с компонентом. |
| `armLength` | Максимальная длина «руки», на которой держится взятый объект. |
| `throwPower` | Сила броска. Масса объекта уменьшает итоговую скорость запуска. |
| `wallLayers` | Слои, считающиеся стенами. Взятый объект, ушедший за такой слой, отпускается. |

**`InteractionObject` (подсветка при наведении)**

| Поле | Описание |
|---|---|
| `Outline Color` | Цвет подсветки под прицелом. |
| `Outline Width` | Толщина подсветки в экранном пространстве. |
| `Outline Mode` | Когда подсветка рисуется относительно глубины сцены. |

Для более глубокой настройки джойнта (жёсткость пружин, максимальная сила, лимит) измени константы в `HandJointController`.

## Обводка

`Outline` — самостоятельный компонент подсветки без сторонних зависимостей. Он рисует силуэт методом «вывернутой оболочки»: меш выдавливается вдоль сглаженных нормалей и заливается сплошным цветом, а трафаретная маска не даёт обводке залезать на сам объект. Используются два одно-пассовых материала (mask + fill), поэтому обводка корректно рисуется и в Built-in Render Pipeline, и в URP, и работает как с `MeshRenderer`, так и со `SkinnedMeshRenderer`.

| Свойство | Описание |
|---|---|
| `OutlineMode` | `OutlineVisible` (по умолчанию), `OutlineHidden` (сквозь стены), `OutlineAll`. |
| `OutlineColor` | Цвет обводки; альфа-канал задаёт непрозрачность. |
| `OutlineWidth` | Толщина в экранном пространстве, `0`–`10`. |

```csharp
var outline = gameObject.GetComponent<Outline>();
outline.OutlineColor = Color.cyan;
outline.OutlineWidth = 6f;
outline.OutlineMode = Outline.Mode.OutlineVisible;
outline.enabled = true;
```

## Авто-сброс за стеной

Пока объект удерживается, обработчик держит линию видимости от «глаз» до объекта. Если между игроком и объектом оказывается коллайдер на слое из маски `Wall Layers` — объект ушёл за стену, — он отпускается автоматически.

Назначь `Wall Layers` на слой(и) геометрии уровня, а интерактивные предметы держи на другом слое. Проверка игнорирует собственные коллайдеры удерживаемого объекта, а пустая маска отключает поведение.

## Публичный API

| Член | Тип | Описание |
|---|---|---|
| `InteractionObjectTaker.Interaction()` | метод | Берёт объект под прицелом или кладёт его. |
| `InteractionObjectTaker.ThrowObject()` | метод | Бросает удерживаемый объект вперёд. |
| `InteractionObject.SetOutline(bool)` | метод | Показывает или скрывает подсветку. |
| `InteractionObject.Rigidbody` | свойство | Закешированный `Rigidbody` объекта. |

Все рантайм-типы находятся в неймспейсе `SST.InteractionObjects`.

## Демо

В папке `Samples` лежат `Demo Scene` и контроллер `PlayerInteractionInput` — примитивная связка от первого лица (движение на WASD, осмотр мышью, взятие и бросок), показывающая все части вместе.

Демо-контроллер поддерживает **оба бэкенда ввода**. Он компилируется под легаси Input Manager или новый Input System в зависимости от `ENABLE_INPUT_SYSTEM`, поэтому работает при любом значении *Active Input Handling* (Player Settings) — Old, New или Both — без добавления зависимости в пакет. При новом Input System клавиши взятия/броска зафиксированы на **E** и **левую кнопку мыши**; сериализуемые поля KeyCode относятся только к легаси-бэкенду.
